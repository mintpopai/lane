# 安全问题报告 / Security Policy

**请勿通过公开 issue 报告安全漏洞。**

请使用本仓库的 [Private vulnerability reporting](../../security/advisories/new) 私下提交，或通过 [联系我们](https://mintpop.ai/zh/contact) 与我们取得联系。报告中请尽量包含：受影响的组件（桌面客户端 / 控制台 / 官网）与版本、复现步骤、可能的影响。

我们会在收到报告后尽快确认，并在修复发布后告知你。

---

**Please do not report security vulnerabilities through public issues.**

Report them privately via this repository's [Private vulnerability reporting](../../security/advisories/new), or [contact us](https://mintpop.ai/contact). Please include the affected component (desktop app / console / website) and version, steps to reproduce, and the potential impact.

We will acknowledge your report as soon as possible and let you know once a fix is released.
